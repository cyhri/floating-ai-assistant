Floating AI Assistant - Test Environment

Use this page to verify floating window interactions, selection capture, and Gemini API answers.

Important Local Testing Instructions:
  1. If viewing via file://, make sure you toggled "Allow access to file URLs" ON for "Floating AI Assistant" in chrome://extensions.
  2. Open the assistant using the bottom-right floating bubble or the Alt+Shift+Q shortcut.
  3. Open Settings (gear icon in the window title bar) to save your Gemini API key.
  4. Highlight any question below, click "Use selection", and click "Ask".
